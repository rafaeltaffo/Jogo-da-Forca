# Jogo da Forca

Projeto pessoal de Rafael Taffo Montanha

Um simples jogo da forca para treinar a linguagem C.

## Sobre

Jogo da forca desenvolvido em C, com dois modos de jogo:
- IA ( Sistema escolhe uma palavra da lista pré definida )
- 2 Jogadores ( Um jogador escolhe uma palavra aleatória para o outro acertar )

> **Nota:** o modo "2 Jogadores" ainda está em desenvolvimento.

## Como jogar

1. Compile o projeto com `g++ Jogo-da-Forca.cpp -o forca`
2. Execute o programa gerado
3. Escolha entre jogar contra IA ou em 2 jogadores
4. Escolha entre adivinhar letras ou chutar a palavra completa
5. Você tem 6 vidas — perde uma a cada letra errada ou todas ao chutar a palavra errada

## Tecnologias

- Linguagem C
